Point-in-time contract

Every source row must satisfy all four conditions to contribute at as_of:

event_time      <  as_of     -- strictly past
knowledge_time  <= as_of     -- already ingested
valid_until     >  as_of     -- not cancelled / reversed
deferred col    known_at <= as_of
